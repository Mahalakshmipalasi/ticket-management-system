# ticket-management-system
A clean, responsive web application built to create, track, and manage support tickets efficiently. 

## Features
- **Ticket Dashboard:** View real-time statistics for total, open/assigned, in-progress/Hold, and resolved/Closed tickets.
- **Full CRUD Actions:** Create new tickets, edit details, view complete notes, or delete tickets.
- **Search & Filter:** Instantly search tickets by title or requester, and filter them by status.
- **Local Storage:** Automatically saves your data right in your browser so your tickets don't disappear on refresh.

## Built With
- **HTML5** for structure
- **CSS3** for styling and responsive design
- **JavaScript (Vanilla)** for interactivity and state management
